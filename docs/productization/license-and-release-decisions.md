# Release-owner decisions

The following decisions remain intentionally open:

- LICENSE_DECISION_REQUIRED: select and add an appropriate license before
  public distribution.
- SECURITY_CONTACT_REQUIRED: select a private vulnerability-reporting
  destination and replace the placeholder in SECURITY.md.
- PUBLIC_OR_PRIVATE_INITIAL_GITHUB_REPOSITORY: decide whether the initial
  repository is public or private and approve its owner and visibility.
- CODE_OF_CONDUCT_OPTIONAL: decide later whether a repository Code of Conduct
  is needed; Phase 1 does not add one automatically.

Phase 1 does not make these decisions, create a remote, or publish anything.
